# MO1 - 1 Binary Conversion

This is a simple console application for binary and decimal conversion, inside you will find current state of the program and
at the bottom the assignment version.

This was my first programming assignment for comp sci 1. I decided to redo them to fortify fundamentals in programming.
Future repo that are old programming assignment if it can be extended (for example like this one turned into a semi-working binary decimal conversion application), then I will also create a (semi or fully) functional program application for those assignments or wait of until I complete all assignments to come back and reinforce more advance methods. Otherwise will just consist of basic assignment requirements.

My goal is to demonstrate self-growth and continuous improvement in efficiency and performance through my GitHub.

How to use: 
User be prompted a menu option for either Binary to Decimal or vice versa or exit program.
Select either and user will be sent to the appropriate conversion.
After inputting either binary sequence or decimal value, the program will output result.
