# MO1-1 Binary Conversion

This is a simple console application for binary and decimal conversion, inside you will find current state of the program and
at the bottom the assignment version.

This was my first programming assignment for comp sci 1. I decided to redo them to fortify fundementals in programming.
Future repo that are old programming assignment if it can be extended (for example like this one turned into a full binary decimal conversion application), I will also create a functional program for them. Otherwise will just consist of basic assignment.

My goal is to demostrate growth and continuos improvement in efficiency and performance. Maybe add new features if applicable.

How to use: 
Will be promted a menu option for either Binary to Decimal or vice versa or exit program.
Select either and will be sent to the appropriate conversion.
After inputting either binary sequence or decimal value, the program will output result.
